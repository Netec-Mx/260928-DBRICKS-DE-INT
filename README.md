# Data Engineering with Databricks

Este curso proporciona las competencias necesarias para diseñar, construir, orquestar y optimizar pipelines de datos utilizando la plataforma Databricks dentro de una arquitectura Lakehouse. A lo largo del programa, los participantes desarrollarán habilidades prácticas en ingesta y transformación de datos con Delta Lake, procesamiento incremental y optimización de tablas, orquestación de flujos con Databricks Workflows, construcción de pipelines declarativos con Delta Live Tables, gobernanza y control de acceso con Unity Catalog, y diseño de soluciones eficientes y listas para producción.
